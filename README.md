# Inventory API migration guide example

This repo is the companion to my freeCodeCamp tutorial on how to write an API migration guide. It uses a sample API, the Inventory API, that's moving from v1 to v2.

## What's in this repo

| File | What it is |
|---|---|
| `v1-reference.md` | Reference docs for Inventory API v1 |
| `v2-reference.md` | Reference docs for Inventory API v2 |
| `migration-guide.md` | The finished migration guide from v1 to v2 |

You can also read the finished guide on my blog: [Migrating from Inventory API v1 to v2](https://chosenvincent.hashnode.dev/migrating-from-inventory-api-v1-to-v2).

The Inventory API is a sample API made for the tutorial. It isn't a real service, so the code examples won't run against a live server.
